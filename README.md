# EaleyImages Website Content

Content and structure package for the EaleyImages Squarespace site
(editorial photography, based in Cary, NC — serving RTP & the Triangle).

## Structure

- `docs/content-package-source.md` — source of truth for brand facts,
  confirmed pricing, and product details. Update this first if anything
  changes.
- `docs/sitemap.md` — navigation and page structure plan.
- `content/homepage.md` — page-ready homepage copy.
- `content/about.md` — page-ready About page copy.
- `content/portfolio-structure.md` — portfolio categories and image plan.
- `content/pricing.md` — page-ready Services & Pricing copy.
- `content/prints-albums.md` — page-ready Prints & Albums copy.
- `content/seo-keywords.md` — page titles, meta descriptions, keyword
  targets.
- `content/contact-and-emails.md` — Contact page copy and the gallery
  delivery email template.

## How to use this

Everything in `/content` is meant to be copy-pasted directly into the
Squarespace editor, section by section. `[ Bracketed text ]` marks a
button/CTA; *italic notes* mark where an image goes.
