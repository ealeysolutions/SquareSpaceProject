## Implementation notes
- Set image file names and alt text descriptively before upload (e.g.
  `cary-nc-senior-portrait-outdoor.jpg`, not `IMG_4821.jpg`).
- Use one clear H1 per page (the page title/headline); keep body copy
  headings as H2/H3.
- Squarespace: fill in each page's SEO title/description under
  Page Settings → SEO — don't rely on the on-page headline alone.
- Add the business to Google Business Profile as "EaleyImages" in Cary, NC
  — this matters more for local search ranking than on-page keywords alone.
